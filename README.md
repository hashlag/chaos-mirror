# Chaos

A modular C++ library implementing several popular cryptographic algorithms.

This project is of an academic nature.

## Algorithms

Below are some of the algorithms implemented.

### Hash functions

- MD4
- MD5
- SHA-1

### MACs

- HMAC (RFC 2104)

### Stream ciphers

- RC4 (ARC4)

### Block ciphers

- DES

### Block cipher modes

- ECB

### Padding schemes

- PKCS#7
- ISO/IEC 7816-4
